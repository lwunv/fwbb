# G3 Bản đồ sân Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trang sân có chế độ Bản đồ (ghim sân, chấm vị trí, vòng bán kính, bấm ghim xem thẻ sân, "Tìm ở khu vực này"), trang chi tiết có bản đồ nhỏ, form sân có "Chọn trên bản đồ".

**Architecture:** Một component client `MapView` bọc `maplibre-gl`, nạp lười bằng `next/dynamic` (`ssr: false`) chỉ khi cần. Dữ liệu vẫn từ `listVenuesNear` có sẵn; bản đồ chỉ là cách hiển thị khác của cùng truy vấn. Hàm tính toán thuần (zoom theo bán kính, vòng tròn GeoJSON, đổi sân thành điểm) nằm ở `src/lib/map/`.

**Tech Stack:** Next.js 16.2.1, React 19, `maplibre-gl` (ghim đúng phiên bản phát hành ≥ 2 tuần trước 4/11/2026), nền OpenFreeMap, nuqs, framer-motion, vitest + jsdom, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-04-venue-map-g3-design.md`
